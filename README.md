# Pablo_Fernandez_Lomana_Herrera_practicas_duales


## Información Común de la Empresa 
- **Empresa:** GEXXI
- **Ubicación:** Parque Tecnológico de Andalucía (PTA), Málaga.

### Contexto y Tareas Realizadas
- **Plataforma para Empresa de Contratas (Sistema CAE):** Desarrollo de la lógica de negocio, base de datos y diseño de interfaces para una plataforma de Coordinación de Actividades Empresariales.
- **Página Web Personal:** Diseño, maquetación y desarrollo de una página web personal enfocada al perfil profesional.
- **Comunicación Internacional:** Participación activa en diálogos y reuniones de equipo comunicadas íntegramente en inglés con los compañeros.
- **Propuesta de Sostenibilidad:** Elaboración de un plan y propuesta de prácticas sostenibles aplicables al entorno laboral y tecnológico de la empresa.

### Herramientas y Tecnologías Utilizadas
- **Frontend:** Angular, TypeScript.
- **Backend:** Laravel, PHP.
- **Base de Datos:** MySQL.

### Módulos Profesionales Relacionados
Las tareas realizadas han puesto en práctica y ampliado los conocimientos de los siguientes módulos del grado DAW:
- **DWES y DWEC:** Desarrollo del backend y frontend tanto para la plataforma de contratas como para la página personal.
- **Despliegue de Aplicaciones Web (DAW):** Uso de automatizaciones y servicios cloud para los proyectos.
- **Inglés Profesional:** Comunicación directa y fluida con el equipo de trabajo.
